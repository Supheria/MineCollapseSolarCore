# Mine Collapse Solar Core

Mine Collapse Solar Core 是原模组 MineCollapse 的修改版。

原模组项目链接：<https://gitlab.com/zerodind/minecollapse>

## 原模组自述文件内容（截至 2026.4.8）

### MineCollapse

MineCollapse is a standalone port of the rock collapse and landslide mechanics from TerraFirmaCraft. Because TerraFirmaCraft is a total conversion mod that changes many aspects of the game, it's hard to integrate with other mods. MineCollapse, on the other hand, is easier to integrate, since it is more limited in scope, and pairs nicely with mods like Geolosys. You can read more about the collapse mechanic in the TFC Field Guide or watch a YouTube video about it.
